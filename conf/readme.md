# Zy's Computer 操作指南

## Terminal 终端

双击桌面 Terminal 图标打开终端窗口。

### 可用命令

| 命令 | 说明 |
|------|------|
| version | 显示当前版本 |
| pwd | 显示当前目录 |
| ls | 列出文件和目录 |
| date | 显示当前日期和时间 |
| clear | 清屏 |

### 使用方法

1. 在终端底部输入框中输入命令
2. 按 Enter 执行
3. 点击终端任意区域可重新聚焦输入框
4. 按 Esc 关闭终端窗口

## Browser 浏览器

双击桌面 Browser 图标打开浏览器窗口。

### 功能说明

- 在地址栏输入完整的网址（以 http:// 或 https:// 开头）
- 按 Enter 后会显示确认跳转区域
- 点击「确认跳转」按钮将在新标签页打开该网址
- 常用网站列表可直接点击快速访问
